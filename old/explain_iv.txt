In econometrics, we often face the problem of **endogeneity**. This happens when an explanatory variable is correlated with the error term, making standard OLS estimates <UNDERLINE>biased</UNDERLINE> and unreliable.
::: message(level="note")
Endogeneity usually arises from omitted variable bias, measurement error, or simultaneity.
::: wait(click=true)
::: write_speak

import statsmodels.api as sm
from linearmodels.iv import IV2SLS

# Simulate data

n = 1000
z = np.random.normal(size=n) # Instrument
e = np.random.normal(size=n) # Error
x = 0.5 * z + e + np.random.normal(size=n) # X is endogenous (related to e)
y = 2 * x + 3 * e + np.random.normal(size=n) # True beta is 2

# IV Regression

data = pd.DataFrame({'y': y, 'x': x, 'z': z})
data['const'] = 1
result = IV2SLS(data.y, data[['const', 'x']], data.z).fit()
print(result.summary)
