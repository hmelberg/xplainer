# Explain Tutorial Principles

## Structure
- Hook → Context → Show → Use → Check understanding.
- Keep each block short (1–4 lines).
- Use `wait(click=true)` every 1–3 blocks for pacing.

## Writing vs speaking
- Speak more than you write.
- Write only key terms, formulas, or short bullets.
- If a paragraph is long, split it into multiple `::: write_speak` blocks.

## Visuals
- Use `::: draw` for diagrams or geometry.
- Use `::: p5` for dynamic intuition (motion, randomness, feedback).
- Keep visuals small and explain what to notice.

## Interaction
- Use `::: question` after a concept or demo.
- Use short, clear answers; avoid trick questions.

## Clarity
- Use tiny numbers for examples.
- One new idea per section.
- Repeat the key idea in different words at the end.

## Tone & style
- Intelligent adult tone.
- Dry humor is ok if it stays brief.
- Curious, friendly, and precise.
- Avoid condescending or “teacherly” phrasing.
- Prefer concrete language over abstract jargon.
