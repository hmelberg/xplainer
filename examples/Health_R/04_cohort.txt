A cohort is a decision. Before you write a single line of analysis code, you have already made ten decisions by defining who is in and who is out. Today we pin down the ones that matter.

::: write_speak
Now that we can link people across tables from Lecture 3, we can finally ask: which of those people are actually in our study?

::: new_page(title="The running question", transition=wipe-left)

::: write_speak
Our clinical target is the same as always: adults newly diagnosed with type 2 diabetes. But "newly diagnosed" is doing a lot of heavy lifting in that sentence. Let us be ruthless about what we mean.

::: accordion(title="Inclusion and exclusion criteria", open=true)
- **Include**: at least one E11 diagnosis in `patient_registry`
- **Include**: first-ever E11 record falls between 2012-01-01 and 2020-12-31
- **Include**: age 18 or older on the date of that first E11
- **Include**: alive on that date (death_date is NA or later)
- **Exclude**: any prior E10 (type 1 diabetes) diagnosis — ever
- **Exclude**: anyone whose first E11 is outside the 2012-2020 window

::: message(level=info, icon=pin)
The **index date** is the anchor point in time from which everything else is measured, for each person. For this cohort, it is the date of their first-ever E11 record. Every lecture from here on uses this concept — Table 1, exposure windows, follow-up, survival curves. All of it hangs on the index date.

::: new_page(title="Finding the index date", transition=cross-dissolve)

::: write_speak
Here is the move. Filter the patient registry to E11 rows, group by person, take the minimum admission date. That minimum is the index date. One row per person, guaranteed.

::: r(auto_run=before, title="Finding the index date")
library(dplyr)  # our verbs for table surgery
library(lubridate)  # for time arithmetic later

# Start from the full patient registry from Lecture 3
index_dates <- patient_registry |>
  filter(str_detect(icd10_main, "^E11")) |>   # keep only type 2 diabetes rows
  group_by(person_id) |>                       # one bucket per person
  slice_min(admission_date, n = 1, with_ties = FALSE) |>  # earliest row wins
  ungroup() |>
  select(person_id, index_date = admission_date)  # rename for clarity

nrow(index_dates)  # how many people have any E11 ever

::: write_speak
`slice_min` is the tidy way to say "take the smallest, break ties cleanly, give me back one row per group". You could also write it as `filter(admission_date == min(admission_date))`, but slice_min tells the reader your intent.

::: new_page(title="Applying exclusions", transition=fade)

::: write_speak
Now we whittle. We want adults with their first E11 inside the 2012 to 2020 window, alive at that moment, and no earlier E10 record on file.

::: r(auto_run=before, title="Applying exclusions")
# Pull in birth_date and death_date from the person table
cohort <- index_dates |>
  left_join(person, by = "person_id") |>  # bring demographics alongside
  filter(index_date >= ymd("2012-01-01"),  # first E11 on or after 2012
         index_date <= ymd("2020-12-31")) |>  # and on or before 2020
  mutate(age_at_index = time_length(index_date - birth_date, "years")) |>  # age in fractional years
  filter(age_at_index >= 18) |>  # adults only
  filter(is.na(death_date) | death_date >= index_date)  # alive at index — defensive check

# People with any prior E10 — we want to drop them
prior_e10 <- patient_registry |>
  filter(str_detect(icd10_main, "^E10")) |>  # type 1 diabetes rows
  distinct(person_id)  # one row per person is enough

cohort <- cohort |>
  anti_join(prior_e10, by = "person_id")  # remove anyone with any E10 ever

nrow(cohort)  # the size of our final cohort

::: message(level=warn, icon=shield)
The "alive at index" filter should remove zero people — you cannot be diagnosed after you die. Code it anyway. Defensive filters catch upstream data errors that would otherwise silently poison your results.
