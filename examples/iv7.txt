In health economics, we call this the "endogeneity problem." Our treatment (surgery) is correlated with the error term (the patient's baseline health).

To fix this, we need an **Instrumental Variable (I.V.)**—a sort of "natural experiment" that nudges some people into surgery for reasons that have nothing to do with their health.

::: title(title=The Two Requirements of an Instrument)

::: write_speak
A valid instrument $Z$ must satisfy two strict rules to help us find the true effect of $X$ on $Y$.

::: table
| Requirement | Definition | Intuition |
| :--- | :--- | :--- |
| **Relevance** | $Z$ must be correlated with $X$ | The instrument must actually change the behavior we are studying. |
| **Exogeneity** | $Z$ must be uncorrelated with the error term | The instrument must be as good as randomly assigned; it shouldn't affect $Y$ except through $X$. |

:::mark("Relevance", speak="The instrument must be correlated with the treatment.")
:::mark("Exogeneity", speak="The instrument must **not** be correlated with the outcome.")

::: write_speak
Let's use a classic health economics example: **Differential Distance**. 

::: write_speak
If you live 2 miles from a "High-Tech" hospital, you are more likely to get the surgery than if you live 20 miles away. 

::: write_speak
Does distance affect your heart health directly? Probably not. Does it affect whether you get surgery? Definitely.

::: question
If "Distance to Hospital" is our instrument, which condition is violated if people who care more about their health specifically choose to live closer to specialized hospitals?
* Exogeneity (The Exclusion Restriction)

::: write_speak
To implement this, we use a technique called **Two-Stage Least Squares (2SLS)**. 

::: write_speak
In **Stage 1**, we use the instrument (Distance) to predict the treatment (Surgery). This "cleans" the treatment of any correlation with the patient's hidden health status.

::: math
Surgery_i = \pi_0 + \pi_1 Distance_i + \nu_i

::: write_speak
In **Stage 2**, we use those *predicted* values ($\widehat{Surgery}_i$) to estimate the effect on Life Expectancy.

::: math
LifeExp_i = \beta_0 + \beta_{IV} \widehat{Surgery}_i + \epsilon_i

::: python(title="Simulating 2SLS in Python", auto_run=after)
import pandas as pd
import numpy as np
import statsmodels.api as sm

# 1. Create fake data
np.random.seed(42)
n = 1000

# Hidden Health: affects both Surgery (X) and Life Expectancy (Y)
health = np.random.normal(0, 1, n)

# Instrument (Z): distance to hospital (affects X, unrelated to health)
dist = np.random.uniform(0, 50, n)

# Surgery (X): endogenous (binary)
surgery_prob = 0.5 - (0.01 * dist) + (0.2 * health) + np.random.normal(0, 0.1, n)
surgery = (surgery_prob > 0.4).astype(int)

# Life expectancy (Y)
life_exp = 70 + 5 * surgery + 10 * health + np.random.normal(0, 1, n)

# 2. Prepare DataFrame
df = pd.DataFrame({"Y": life_exp, "X": surgery, "Z": dist})
df["Intercept"] = 1.0

# 3. 2SLS using statsmodels only
# First stage: X ~ Intercept + Z
first_stage = sm.OLS(df["X"], df[["Intercept", "Z"]]).fit()

# Predicted X (a.k.a. X-hat)
df["X_hat"] = first_stage.fittedvalues

# Second stage: Y ~ Intercept + X_hat
second_stage = sm.OLS(df["Y"], df[["Intercept", "X_hat"]]).fit()

print("--- First stage: X ~ Z ---")
print(first_stage.summary())

print("\n--- Second stage (2SLS): Y ~ X_hat ---")
print(second_stage.summary())

# If you want heteroskedasticity-robust SEs for the second stage:
second_stage_robust = second_stage.get_robustcov_results(cov_type="HC1")
print("\n--- Second stage with robust SEs (HC1) ---")
print(second_stage_robust.summary())
:::

::: write_speak
Notice the coefficient for $X$. That is our **Local Average Treatment Effect (LATE)**. 

::: write_speak
It's "Local" because it only tells us the effect for "compliers"—people who got the surgery *because* they lived close by, but wouldn't have otherwise.

::: title(title="The Exclusion Restriction Trap")

::: write_speak
The hardest part of Instrumental Variables is defending the **Exclusion Restriction**. You have to argue that the instrument has *zero* direct effect on the outcome.



::: multiple_choice
Suppose we use "State of Birth" as an instrument for "Years of Education" to see the effect on "Income." If people born in wealthier states get better nutrition (affecting future income directly), is the instrument valid?
Yes, because State of Birth is random.
* No, it violates the Exclusion Restriction.
No, it violates the Relevance condition.
Yes, but only for people who didn't move.

::: title(title=Summary & Further Reading)

::: write_speak
Instrumental Variables are a powerful tool to move from **correlation to causation** when randomized controlled trials are impossible or unethical.

::: write_speak
Just remember: an instrument is only as good as the story you tell to defend its exogeneity.
