::: title
Chart.js web component (comp-chart)

::: write
This uses the <strong>comp-chart</strong> component, which wraps <a href="https://www.chartjs.org/docs/latest/">Chart.js</a>. The component is loaded automatically from <code>components/comp-chart.js</code>. The block body is the full Chart.js config (JSON): <code>type</code>, <code>data</code>, <code>options</code>.

::: web_defaults
comp-chart=config

::: write
Bar chart (simple):

::: comp comp-chart
{"type":"bar","data":{"labels":["Red","Blue","Yellow","Green","Purple","Orange"],"datasets":[{"label":"# of Votes","data":[12,19,3,5,2,3],"borderWidth":1}]},"options":{"scales":{"y":{"beginAtZero":true}}}}

::: write
Line chart with two datasets:

::: comp comp-chart
{
  "type": "line",
  "data": {
    "labels": ["Jan", "Feb", "Mar", "Apr", "May", "Jun"],
    "datasets": [
      { "label": "Series A", "data": [65, 59, 80, 81, 56, 55], "fill": false, "borderColor": "rgb(75, 192, 192)", "tension": 0.1 },
      { "label": "Series B", "data": [28, 48, 40, 19, 86, 27], "fill": false, "borderColor": "rgb(255, 99, 132)", "tension": 0.1 }
    ]
  },
  "options": { "scales": { "y": { "beginAtZero": true } } }
}

::: write
Pie chart:

::: comp comp-chart
{"type":"pie","data":{"labels":["A","B","C","D"],"datasets":[{"data":[30,50,12,8],"backgroundColor":["#ff6384","#36a2eb","#ffce56","#4bc0c0"]}]}}

::: write
You can pass <code>type</code>, <code>data</code>, <code>options</code>, and <code>plugins</code> exactly as in the <a href="https://www.chartjs.org/docs/latest/configuration/">Chart.js docs</a>. Use <code>center</code> to center the chart in the column.

::: comp comp-chart(center)
{"type":"bar","data":{"labels":["Q1","Q2","Q3","Q4"],"datasets":[{"label":"Sales","data":[40,50,60,70]}]},"options":{"scales":{"y":{"beginAtZero":true}}}}
